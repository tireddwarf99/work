## Этап 3 — Google-вход и sync Android↔Windows — ✅

- [x] Вход: Android Credential Manager; Windows — системный браузер, OAuth Authorization Code + PKCE S256, state/nonce, loopback 127.0.0.1
- [x] Одинаковый Firebase UID на обеих платформах (проверено на реальных устройствах)
- [x] Токены в защищённом хранилище ОС (Keystore / DPAPI), refresh-цикл, повторный вход только при истечении/отзыве
- [x] Firestore REST + Security Rules по UID владельца (с валидацией формы документов)
- [x] Протокол §10: outbox в одной транзакции с мутацией; push — транзакции с commit_seq и precondition; pull — курсор после локальной транзакции; защита повторного push (batchGet + revision guard + last_op_id)
- [x] Автослияние трёхстороннее по sync_base; конфликты → раздел «Конфлікти» с решением
- [x] Удаление против редактирования: позднее действие побеждает, при равенстве — удаление
- [x] Первый вход объединяет данные (pull-first); выход с выбором копии; workspace привязан к аккаунту
- [x] Смена epoch сервера — только явное подтверждение с JSON-бэкапом несинхронизированного
- [x] Ошибки сети/квот видны, outbox сохраняется; интервалы 30 с + ручная синхронизация
- [x] Экран диагностики с журналом событий
